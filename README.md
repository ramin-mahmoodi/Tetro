# TETRO // ردیاب زنده قیمت تتر (USDT)

یک وب‌اپلیکیشن پیش‌رونده (PWA) فوق‌العاده سریع، مینیمال، مدرن و کاملاً واکنش‌گرا برای رصد زنده قیمت لحظه‌ای تتر (USDT) در صرافی‌های برتر ایرانی و بین‌المللی با تمرکز انحصاری بر **قیمت‌ها و نمودارها**.

طراحی بصری این پروژه بر اساس کانسپت رترو-بروتالیست الهام‌گرفته از `hyper-link-a-sandbox-concept` با سیستم استایل‌دهی ماژولار و متغیرهای استاندارد CSS پیاده‌سازی شده است.

---

## ویژگی‌های کلیدی

- **۵۸ پالت رنگی کامل**: شامل دسته‌بندی‌های Basic (۸ تم)، Premium (۲۲ تم)، Special (۹ تم)، Monochrome (۱۱ تم) و Holiday (۸ تم).
- **حالت‌های سه‌گانه پایه**: Light Mode، Sepia Mode، Dark Mode به همراه فیلتر Low Contrast.
- **تغییر اندازه زنده قلم (Font Resizer)**: امکان کوچک/بزرگ کردن داینامیک متون با حفظ تناسب خطوط.
- **کاملاً ریسپانسیو و لمس‌محور (Mobile-First Touch UI)**:
  - اهداف لمسی با حداقل اندازه ۴۸ در ۴۸ پیکسل برای سهولت کار با یک دست روی گوشی.
  - نوار ناوبری لمسی شناور در پایین صفحه برای موبایل.
  - سایدبار رترو با خطوط مورب ۴۵ درجه و نشان‌های گرافیکی برای نمایشگرهای دسکتاپ.
- **نمودار تعاملی تم‌پذیر (Interactive Canvas Chart)**:
  - سازگار و هماهنگ خودکار با رنگ‌های پالت جاری.
  - تایم‌فریم‌های متنوع: ۱ ساعته (1H)، ۲۴ ساعته (24H)، ۷ روزه (7D)، ۳۰ روزه (30D) و ۱ ساله (1Y).
  - پشتیبانی از تاچ، درگ و نمایش خطوط متقاطع (Crosshair) و تولتیپ قیمت.
  - قابلیت فیلتر بر اساس منبع (میانگین یا تک‌تک صرافی‌ها).
- **شبکه کارت‌های صرافی**:
  - نوبیتکس، والکس، رمزینکس، آبان‌تتر، تترلند، تبدیل، اکسیر و تتر جهانی بایننس.
  - نمایش همزمان نرخ خرید، فروش، اسپرد (اختلاف) و درصد نوسان ۲۴ ساعته.
  - افکت فلاش ملایم سبز/قرمز هنگام بروزرسانی زنده قیمت‌ها.
  - امکان مرتب‌سازی (ارزان‌ترین خرید، گران‌ترین فروش، کمترین اسپرد) و جستجو.
- **پشتیبانی کامل از PWA**:
  - قابل نصب روی اندروید، iOS، ویندوز و مک به عنوان اپلیکیشن مستقل.
  - کش آفلاین با سرویس‌ورکر جهت لود آنی.
- **بروزرسانی خودکار با گیت‌هاب اکشن (GitHub Actions)**:
  - دریافت دوره‌ای داده‌های واقعی و انتشار بدون وقفه روی GitHub Pages.

## ساختار فایل‌ها

```
Tetro/
├── index.html                   # ساختار اصلی برنامه و مارک‌آپ سمانتیک
├── manifest.json                # مانیفست PWA
├── sw.js                        # سرویس‌ورکر کش آفلاین
├── css/
│   ├── tokens.css               # توکن‌ها و متغیرهای پایه
│   ├── themes.css               # ۵۸ پالت رنگی و حالات ۳ گانه
│   ├── layout.css               # گرید و ناوبری ریسپانسیو
│   ├── components.css           # المان‌های بروتالیست، کارت‌ها و مودال
│   └── chart.css                # استایل‌های نمودار تعاملی
├── js/
│   ├── theme-engine.js          # موتور کنترل تم‌ها و حالت‌ها
│   ├── data-adapter.js          # آداپتور جریان داده و شبیه‌ساز زنده
│   ├── chart-engine.js          # رندر چارت کنواس با لمس
│   ├── ui-renderer.js           # رندر کارت‌ها و تیکرهای زنده
│   └── app.js                   # نقطه ورود و راه‌اندازی PWA
└── assets/
    ├── favicon.svg              # فاویکون وکتور
    └── icons/                   # آیکون‌های استاندارد PWA
```

## نحوه اجرای محلی

کافی است یک وب‌سرور استاتیک ساده مانند `npx serve` یا اکستنشن Live Server در دایرکتوری پروژه اجرا شود:

```bash
# با استفاده از Node:
npx serve .

# یا با استفاده از پایتون:
python -m http.server 8080
```
سپس آدرس `http://localhost:8080` را در مرورگر باز کنید.
