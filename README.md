# Tetro

> سامانه سریع، مدرن و مستقل برای رصد لحظه‌ای و تحلیل قیمت تتر (USDT) در صرافی‌های برتر ایران.

تترو (Tetro) یک وب‌اپلیکیشن پیش‌رونده (PWA) سبک و مستقل است که با هدف مقایسه شفاف نرخ خرید و فروش تتر، نمایش اسپرد قیمت‌ها و تحلیل داده‌های تکنیکال در بازار رمزارز ایران طراحی شده است.

---

## قابلیت‌های کلیدی

- **رصد زنده صرافی‌های معتبر:** دریافت و مقایسه نرخ لحظه‌ای نوبیتکس، والکس، رمزینکس، آبان‌تتر، تترلند، تبدیل، اکسیر و بیت‌پین.
- **نمودار تعاملی و پرسرعت (HTML5 Canvas):** نمایش نمودارهای شمعی (Candlestick) و خطی (Line) به همراه حجم معاملات در تایم‌فریم‌های ۱ ساعته، ۲۴ ساعته، ۷ روزه، ۳۰ روزه و ۱ ساله.
- **میانگین وزنی بازار (VWAP):** محاسبه شاخص واقعی قیمت بر اساس حجم معاملات همراه با فیلتر هوشمند حذف داده‌های نامتعارف و پرت (Outliers).
- **تشخیص خودکار بازار راکد:** شناسایی هوشمند صرافی‌های فاقد داده یا تعطیل‌شده در بازه‌های خارج از تایم معاملات.
- **طراحی بهینه‌شده لمسی و ریسپانسیو:** ناوبری روان در موبایل و دسکتاپ با دسترسی‌پذیری بالا.
- **شخصی‌سازی گسترده:** پشتیبانی از ۵۸ پالت رنگی متنوع در حالت‌های روشن، تاریک و سپیا با ذخیره‌سازی محلی.
- **معماری PWA با پشتیبانی آفلاین:** قابلیت نصب روی تمام پلتفرم‌ها (موبایل و دسکتاپ) بدون وابستگی به فریم‌ورک‌های سنگین خارجی.

## ساختار پروژه

```
Tetro/
├── index.html                 # رابط کاربری اصلی و ساختار سمانتیک
├── manifest.json              # تنظیمات PWA و نصب نرم‌افزار
├── sw.js                      # سرویس‌ورکر مدیریت کش و حالت آفلاین
├── server.js                  # سرور توسعه لوکال و ایمن برای فایل‌های ایستا
├── js/
│   ├── data-adapter.js        # هسته پردازش داده‌ها، محاسبات و کشینگ
│   ├── chart-engine.js        # موتور ترسیم نمودار روی Canvas
│   ├── ui-renderer.js         # مدیریت رندر جدول و شاخص‌های آماری
│   ├── theme-engine.js        # موتور تم و پالت‌های رنگی
│   └── app.js                 # راه‌انداز اصلی و شورت‌کات‌ها
├── css/                       # استایل‌های پیمانه‌ای و متغیرهای طراحی
├── scripts/
│   ├── fetch-market-data.js   # اسکریپت واکشی و تجمیع داده‌ها از API صرافی‌ها
│   └── build.js               # تولید خروجی ایستا (dist) جهت استقرار
├── tests/                     # تست‌های واحد اعتبارسنجی محاسبات
└── data/market.json           # اسنپ‌شات تاییدشده و کش نرخ‌ها و کندل‌ها
```
