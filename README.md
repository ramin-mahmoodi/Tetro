# TETRO // ردیاب زنده قیمت تتر (USDT)

یک وب‌اپلیکیشن پیش‌رونده (PWA) فوق‌العاده سریع، مینیمال، مدرن و کاملاً واکنش‌گرا برای رصد زنده قیمت لحظه‌ای تتر (USDT) در صرافی‌های برتر ایرانی و بین‌المللی با تمرکز انحصاری بر **قیمت‌ها و نمودارها**.

طراحی بصری این پروژه بر اساس کانسپت رترو-بروتالیست الهام‌گرفته از `hyper-link-a-sandbox-concept` با سیستم استایل‌دهی ماژولار و متغیرهای استاندارد CSS پیاده‌سازی شده است.

---

## ویژگی‌های کلیدی

- **۵۸ پالت رنگی کامل**: شامل دسته‌بندی‌های Basic (۸ تم)، Premium (۲۲ تم)، Special (۹ تم)، Monochrome (۱۱ تم) و Holiday (۸ تم).
- **حالت‌های سه‌گانه پایه**: Light Mode، Sepia Mode، Dark Mode به همراه فیلتر Low Contrast.
- **تغییر اندازه زنده قلم (Font Resizer)**: امکان کوچک/بزرگ کردن داینامیک متون با حفظ تناسب خطوط.
- **کاملاً ریسپانسیو و لمس‌محور (Mobile-First Touch UI)**:
  - اهداف لمسی با حداقل اندازه ۴۸ در ۴۸ پیکسل برای سهولت کار با یک دست روی گوشی.
  - نوار ناوبری لمسی شناور در پایین صفحه برای موبایل.
  - سایدبار رترو با خطوط مورب ۴۵ درجه و نشان‌های گرافیکی برای نمایشگرهای دسکتاپ.
- **نمودار تعاملی تم‌پذیر (Interactive Canvas Chart)**:
  - دو حالت نمایش: شمعی ژاپنی (Candlestick) و خطی (Line) به همراه میله‌های حجم (Volume).
  - سازگار و هماهنگ خودکار با رنگ‌های پالت جاری.
  - تایم‌فریم‌های متنوع: ۱ ساعته (1H)، ۲۴ ساعته (24H)، ۷ روزه (7D)، ۳۰ روزه (30D) و ۱ ساله (1Y).
  - پشتیبانی از تاچ، درگ، نمایش دقیق خطوط متقاطع (Crosshair)، تولتیپ قیمت، و محور قیمت عمودی (Y-Axis).
  - تجمیع و خوشه‌بندی داینامیک کندل‌ها روی موبایل جهت جلوگیری از تداخل و همپوشانی شمع‌ها.
  - زمان‌بندی و برچسب‌های استاندارد با منطقه زمانی تهران (`Asia/Tehran`).
- **جدول صرافی‌های برتر ایرانی**:
  - نوبیتکس، والکس، رمزینکس، آبان‌تتر، تترلند، تبدیل، اکسیر و بیت‌پین.
  - نمودارهای خطی کوچک ۲۴ ساعته (Sparkline) مشتق‌شده مستقیم از کندل‌های ۲۴ ساعته واقعی.
  - نمایش همزمان نرخ خرید، فروش، دامنه نوسان (کف و سقف ۲۴ ساعته) و درصد نوسان تا دو رقم اعشار.
  - وضعیت سلامت صرافی‌ها (`live`، `stale`، `failed`) به همراه تاریخ آخرین بروزرسانی موفق (`lastSuccessAt`).
  - افکت فلاش ملایم سبز/قرمز هنگام بروزرسانی زنده قیمت‌ها.
  - امکان مرتب‌سازی (ارزان‌ترین خرید، گران‌ترین فروش، نام صرافی) و جستجوی لحظه‌ای.
- **پشتیبانی ۱۰۰٪ آفلاین PWA**:
  - قابل نصب روی اندروید، iOS، ویندوز و مک به عنوان اپلیکیشن مستقل.
  - استقلال کامل از CDNهای خارجی (مانند unpkg) و میزبانی محلی فونت‌ها و آیکون‌های Phosphor.
  - سرویس‌ورکر امن با ساختار نرمالایزشده (بدون نشت حافظه ناشی از query string).
  - توقف خودکار Polling هنگام مخفی شدن تب جهت حفظ باتری و کاهش مصرف اینترنت.
- **بروزرسانی خودکار با گیت‌هاب اکشن (GitHub Actions)**:
  - اجرای خودکار هر ۱۰ دقیقه یک‌بار با کرون جاب (`*/10 * * * *`).
  - اعتبارسنجی حد آستانه داده‌ها (توقف و خطای CI در صورت دریافت کمتر از ۴ صرافی جهت جلوگیری از مخدوش شدن داده‌ها).
  - پشتیبانی از پروکسی (`IRAN_PROXY` / `HTTPS_PROXY`) جهت دور زدن محدودیت‌های Geo-IP سرورهای گیت‌هاب برای صرافی‌های ایرانی.

## ساختار فایل‌ها

```
Tetro/
├── index.html                   # ساختار اصلی برنامه و مارک‌آپ سمانتیک
├── manifest.json                # مانیفست PWA با مسیرهای نسبی
├── sw.js                        # سرویس‌ورکر کش آفلاین و مدیریت منابع
├── server.js                    # سرور امن توسعه محلی با پروکسی و ضد SSRF
├── css/
│   ├── tokens.css               # توکن‌ها و متغیرهای پایه
│   ├── themes.css               # ۵۸ پالت رنگی و حالات ۳ گانه
│   ├── layout.css               # گرید و ناوبری ریسپانسیو
│   ├── components.css           # المان‌های بروتالیست، جدول صرافی‌ها و نشان‌ها
│   ├── chart.css                # استایل‌های چارت تعاملی
│   └── phosphor.css             # استایل‌های محلی آیکون‌های فسفر
├── js/
│   ├── theme-engine.js          # موتور کنترل تم‌ها و حالت‌ها
│   ├── data-adapter.js          # دریافت و نرمال‌سازی داده‌ها و مدیریت Polling
│   ├── chart-engine.js          # رندر چارت شمعی و خطی روی کنواس
│   ├── ui-renderer.js           # رندر جدول و کارت‌ها
│   └── app.js                   # کلیدهای میانبر فراگیر و ثبت PWA
├── scripts/
│   ├── fetch-market-data.js     # اسکریپت همگام‌سازی نرخ‌ها و کندل‌ها از APIها
│   └── bundle-icons.js          # اسکریپت دانلود و محلی‌سازی فونت و استایل فسفر
├── data/
│   └── market.json              # اسنپ‌شات واقعی و تاییدشده بازار
└── assets/
    ├── icon.svg                 # آیکون وکتور اصلی
    ├── fonts/                   # فونت‌های محلی آیکون Phosphor
    └── icons/                   # آیکون‌های استاندارد PWA
```

## نحوه اجرای محلی

برای اجرای بهینه سرور توسعه به همراه پروکسی امن جهت دور زدن CORS:

```bash
node server.js
```
سپس آدرس `http://127.0.0.1:4173` را در مرورگر باز کنید.
سرور به صورت سخت‌گیرانه روی `127.0.0.1` با لیست مجاز صرافی‌ها و ضد نفوذ Path Traversal پیکربندی شده است.
